# Микросервис для работы с балансом пользователей

Этот проект представляет собой микросервис для работы с балансом пользователей. Он позволяет начислять средства на баланс, резервировать средства с основного баланса на отдельном счете, признавать выручку и получать баланс пользователя.

## Технологии

* Язык программирования: Golang
* База данных: PostgreSQL
* Docker и Docker Compose для развертывания dev-среды

Пока в процессе разработки.
